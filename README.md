# ZYSTM32-A0 智能小车综合程序

湖南智宇电子 ZYSTM32-A0 智能机器人主板（STM32F103RCT6）综合程序：**黑线循迹 / 超声波避障 / 综合模式**，
板载 PC2 按键循环切换模式。

> 版本演进：`v1.0` 原厂 → `v2.x` 试错 → `v3.0~v3.6` 重构（循迹跑通、PID、超声波避障、融合模式）→ `R1` 灰度极性修复 → `R1.1` 关闭蜂鸣器 → `V5` 5ms 调度 + 模式表 + 高速过弯 → `V6` 覆盖度判别 + 事件分层 + 串口调参 + 自检 → **`V7` MPU6050 + 十字默认直行（当前）**

---

## v3.0 做了什么（重要）

把仓库里的 `可循迹版本/`（实车能稳定循迹的那份）和 v1.0 做了逐文件对比，结论很明确：

| 发现 | 说明 |
|---|---|
| **只有 `IRSEARCH.c/.h` 不同** | 可循迹版本没改电机、没改主循环，说明**原厂 `motor.c` 的通道映射是对的** |
| **v2.0 的电机"修复"是错的** | v2.0 把右轮挪到 CH4，导致 v2.x 车跑不直、循迹失败。v3 已改回：**左轮 CH4/PB9，右轮 CH3/PB8** |
| **v2.1 的 I2C 实现太简陋** | 缺总线恢复、PING 重试、通道使能(0xCE)、归一化(0xCF)，读出来是无效数据 |
| **可循迹版本读的是"归一化模拟量"** | 不是数字量；用 `黑权重 = 180 - 归一化值` 做加权重心，分辨率高得多 |

v3.0 = 可循迹版本的循迹算法 + v2.0 的非阻塞电机层 / 不停车避障 / 串口调试。

## 灰度传感器接线

**默认 I2C 方案**（`IRSEARCH.h` 里 `GRAY_IF_I2C = 1`）：

| 模块 | 接主板 | 说明 |
|---|---|---|
| VCC | 5V | |
| GND | GND | |
| SCL | **PB10**（IO16） | 5V 容忍脚 |
| SDA | **PB11**（IO15） | 5V 容忍脚 |
| PULL 跳线 | **必须短接** | 打开 5V 上拉，不短接通信必失败 |
| AD0 / AD1 | 不装 | 保持默认地址 `0x4C` |

**备选串行方案**（`GRAY_IF_I2C = 0`）：VCC→5V、GND→GND、**CLK→PB10**、**DAT→PB11**；
时序：CLK 拉低 → 2µs → 读 DAT → CLK 拉高 → 5µs，循环 8 次。

## ⚠️ 12cm 前视距离的几何限制（为什么发夹弯跟不住）

灰度板在驱动轴前方 `L`，阵列半宽 `h`（8 路约 7cm 跨度，`h≈3.5cm`）。
车沿半径 `R` 的圆弧走时，**探头处的横向偏移**是几何决定的：

```
δ = L² / (2R)
```

| 弯半径 R | 探头处偏移 δ | 是否在阵列内 |
|---:|---:|:--:|
| 10 cm | **7.2 cm** | ❌ 超出 |
| 15 cm | 4.8 cm | ❌ 超出 |
| 20 cm | 3.6 cm | ⚠️ 临界 |
| 30 cm | 2.4 cm | ✅ |
| 50 cm | 1.4 cm | ✅ |

**结论：12cm 前视 → 能连续跟住的最小弯半径约 20.6cm。**
比这更急的弯（视频里的发夹弯约 8~10cm）**不管 PID 怎么调都会丢线**，
正确的策略是"丢线 → 原地朝最后方向转 → 重新捕获"，v3.3 就是按这个思路调参的。

**根治办法**（如果支架能动）：把灰度板从 12cm 缩短到 5cm，最小弯半径降到 3.6cm，
发夹弯就能连续跟住。3cm 时是 1.3cm。

### PID 调参顺序

1. **先把 KI、KD 都设 0**，只调 P：`GRAY_STEER_GAIN` 从 32 开始，直线画龙就调小（25），压不住弯就调大（45）
2. **前视 12cm 建议 KI 保持 0**：探头看得远，积分容易累积成过冲
3. **D 从 12 开始**：D 在长前视下是"提前收油"，比 I 有用
4. 串口看 `corr`/`spd` 最直观：`corr` 顶到 ±50 说明在满舵过弯，`spd` 掉到 18 说明已减速到底


## 串口调试（115200，插 USB）

```
[BOOT] ZYSTM32-A0 V6  build ...
[BOOT] gray ready = 1 (ok)
[cfg] 从 Flash 读取, 16 项
mode=1 L=  32 R=  32 | err=   0 corr=   0 spd= 32 ev=LINE act=3 cc=0 yaw=  -1 | ready=1 st=0 dist= 45 ang= 90 fus=0
```

- `ready=0` → 灰度模块没通：先查 **PULL 跳线**、SCL/SDA 是否接反、5V 供电
- `err`：0 居中、负数偏左、正数偏右、`999` 丢线、**`998` = 十字后保护期内短暂丢线（正在直行通过）**
- `corr`：转向量（已含"归一化 × 速度补偿"）；`|corr|` 接近 `spd` 时说明内侧轮已被压到 0（满舵过弯）
- `spd`：斜坡 + 速度调度后的基础速度，掉到 25 说明已减速到底
- **`ev`**：`LINE` 正常压线 / `WIDE` 宽黑（十字·横带）/ `LOST` 丢线
- **`act`**：这一帧有几路压线（覆盖度）。正常 2~4；到 7~8 就是压到一大片黑了
- **`cc`**：上电以来过了几个十字/横带
- **`yaw`**：陀螺航向角（度）。静止应基本不动，左转为正；不跟着转说明方向要改 `IMU_YAW_SIGN`
- 手拿车把某个探头压在黑线上，`err` 应有明显正负跳变 → 验证通道顺序

### 串口指令（V6）

一行一条，大小写不敏感：

| 指令 | 作用 |
|---|---|
| `1` / `2` / `3` / `4` | 切模式（整行只能有这一个字符） |
| `?` | 打印全部参数 |
| `BASE 55`（或 `SET BASE 55`） | 改参数，立即生效（还没存盘） |
| `SAVE` | 写入内部 Flash，回读校验后打印 OK/FAIL |
| `LOAD` / `DEF` | 从 Flash 重读 / 恢复默认 |
| `HELP` | 帮助 |

参数名：`BASE GAIN FAR THD KD KI SLOW SLOWD MIN REV CUT FULL REF RAMP WIDE DEAD`。

| **V7** ⭐ | **MPU6050 + 十字路口默认直行**：<br>① 新增 `SYSTEM/imu/`：软件 I2C（PC4=SCL / PC5=SDA，**不与灰度共用总线**，因为灰度的 PULL 是 5V 上拉、MPU6050 不耐 5V），只读 GYRO_Z 积分出 yaw，上电静止 1.5s 自动标零偏（连续读错 20 次自动降级）；<br>② 十字默认直行：进 `EV_WIDE` 锁存 yaw，期间用航向修正代替 PID；出宽黑后 `COAST=250ms` 内若丢线**继续直行**（`err=998`），不再原地找线 —— 十字中间的断线/白缝才是"过不去"的真正原因；<br>③ 新增 3 个参数 `CROSSK/CROSSD/COAST`（串口可调），参数版本升到 2（旧存档自动作废）；<br>④ 没接陀螺时自动退化成 V6 的"锁 0 直行"；<br>⑤ 自检模式加第 7 步（陀螺），调试行加 `yaw` 字段。 |

## 工作模式（R1.1）

| 模式 | 怎么进 | 功能 | 指示灯 |
|---|---|---|---|
| **1 综合** | 上电默认 | **循迹 + 避障**：平时循迹，遇障碍绕过去再找回线 | D4 亮；避让时 D3 亮 |
| **2 纯避障** | 按 1 次 | 超声波 + 舵机扫描（单独调避障参数用） | D4 灭，D3 作障碍指示 |
| **3 纯循迹** | 按 2 次 | **只跑灰度 PID，不避障**（调 PID / 测传感器用） | D4、D3 全亮 |
| **4 自检** | 按 3 次 | 灰度/电机/舵机/超声波/按键/遥控/参数 逐项点名，串口打 PASS/FAIL | 全过 D3 常亮，有失败 D3 灭 |

## 融合模式（R1，模式 1）

```
循迹直行 ──前方 <35cm──→ 停车 → 舵机扫 中90°/左170°/右10° → 选距离大的一侧
    → 转向绕行 600ms → 原地朝反方向慢转找灰度线
    → 找到线（Gray_IsOnLine）→ 冷静 400ms → 回到循迹
```

| 参数（`SYSTEM/app/app_mode.h`） | 默认 | 作用 |
|---|---:|---|
| `FUS_TRIGGER_CM` | 35 | 前方小于它触发避让 |
| `FUS_MIN_GAP_CM` | 20 | 两侧都小于它 → 原地掉头 |
| `FUS_TURN_MS` | 600 | 绕行转向时长（转不够→调大） |
| `FUS_SEEK_SPEED` | 40 | 找线转速（找不到→调大；冲过头→调小） |
| `FUS_SEEK_TIMEOUT_MS` | 2500 | 找线超时，超时先回循迹 |
| `FUS_COOLDOWN_MS` | 400 | 绕完冷静期，防止立刻又触发 |
| `FUS_MEAS_PERIOD_MS` | 100 | 循迹时测距周期 |

## 避障（R1，模式 2 单独使用）

硬件：超声波 **TRIG=PC0 / ECHO=PC1**，舵机 **PB0（TIM3_CH3，50Hz）**。

两版二选一（`IRAvoid.h` 的 `AVOID_SCAN_WHILE_DRIVING`）：

| 值 | 版本 | 行为 |
|---|---|---|
| **0（默认）** | 停车扫描版 | 前方 <40cm → 停车 → 舵机扫 左/中/右 → 选远侧 → 转向 → 回正 |
| 1 | 边走边扫版 | 不停车，舵机 90°±40° 往返扫；前方 ±20° 内 <40cm 朝最空侧弧线绕 |

> 模式 2 只有避障、不循迹，所以绕完会一直直行；要"绕完回线"请用**模式 1（综合）**。

- `SYSTEM/motor/` — 电机（非阻塞 `Motor_SetSpeed` + 原厂兼容接口）

- `SYSTEM/app/` — **模式表** + 四个模式的 start/update/stop
- `SYSTEM/cfg/` — **V6 新增**：运行期参数 + 串口命令 + 内部 Flash 保存
- `SYSTEM/selftest/` — **V6 新增**：模式 4 自检流程
- `SYSTEM/imu/` — **V7 新增**：MPU6050 软件 I2C 驱动 + 航向积分
- `可循迹版本/`、`docs/` — 参考版本与设计文档（不参与编译）
