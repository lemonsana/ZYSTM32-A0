# ZYSTM32-A0 智能小车综合程序

湖南智宇电子 ZYSTM32-A0 智能机器人主板（STM32F103）官方综合例程的整理版本，
包含**黑线循迹 / 红外避障 / 红外遥控**三个实验，通过板载按键切换模式。

> 本仓库按版本迭代：`v1.0` = 厂商原始代码（未修改），后续版本在此基础上修复问题、升级传感器。

---

## 硬件平台

| 项目 | 参数 |
|---|---|
| 主控 | STM32F103（大容量，`STM32F10X_HD`），72 MHz |
| 底盘 | 四驱（左右两组并联驱动，2 路 PWM + 2 路方向脚） |
| 开发环境 | Keil MDK 5（`USER/Template.uvprojx`） |
| 库 | STM32 标准外设库 V3.5.0 |

## 目录结构

```
ZYSTM32-A0/
├── CORE/               CMSIS 内核 + 启动文件（startup_stm32f10x_hd.s）
├── STM32F10x_FWLib/    STM32 标准外设库 V3.5.0
├── SYSTEM/             板级驱动
│   ├── delay/          SysTick 延时
│   ├── sys/            位带宏、WFI、开关中断
│   ├── usart/          串口1 + printf 重定向
│   ├── motor/          电机 PWM/方向、7 个运动函数
│   ├── keysacn/        按键、蜂鸣器、LED
│   ├── IRSEARCH/       黑线循迹（2 路光电对管）
│   ├── IRAvoid/        红外避障（1 路）
│   └── remote/         NEC 红外遥控解码（TIM5 输入捕获）
├── USER/               主程序、时钟、工程文件
├── docs/               版本说明与代码分析
└── README.TXT          厂商原始说明
```

## 功能与模式

| 模式 | 按键切换顺序 | 功能 | 指示灯 |
|---|---|---|---|
| 1 循迹 | 上电默认 | 双光电探头跨黑线跟踪 | D4 亮 |
| 2 避障 | 按 1 次 | 遇障碍 → 停 → 退 → 左转 | D4 灭，D3 作障碍指示 |
| 3 遥控 | 按 2 次 | 红外遥控器控制前进/后退/转向 | D4、D3 全亮 |

## 引脚分配

| 引脚 | 功能 |
|---|---|
| PA1 | 红外遥控接收（TIM5_CH2 输入捕获） |
| PA4 | 右电机方向 |
| PA6 | LED D4 |
| PA7 | 右循迹探头 |
| PB0 | 左循迹探头 |
| PB1 | 避障探头 |
| PB6 | LED D3 |
| PB7 | 左电机方向 |
| PB8 | PWM（TIM4_CH3） |
| PB9 | PWM（TIM4_CH4） |
| PC2 | 模式切换按键 |
| PC3 | 蜂鸣器 |

## 编译 / 烧录

1. 用 Keil MDK 打开 `USER/Template.uvprojx`
2. 编译（工程已配置 `STM32F10X_HD, USE_STDPERIPH_DRIVER`）
3. 用 ST-Link / J-Link 下载到 ZYSTM32-A0 主板

## 已知问题（v1.0，待后续版本修复）

1. **循迹模式异常**：进入循迹后只有左轮单向转动，无法循迹。根因疑似电机 PWM 通道与引脚定义交叉
   （`SetMotorSpeed` 中"右轮"写 `TIM_SetCompare3`，而 `TIM4_CH3` 对应 PB8；头文件却把 PB8 命名为 `LEFT_MOTOR_PWM`）。
   触发特征与实测现象一致：只发左轮指令时，实际只有左轮获得 PWM。
2. **避障动作笨重**：遇障碍先停车 300 ms、后退 400 ms、再左转 500 ms，全程开环定时，动作期间不重新检测。
3. 循迹/避障/遥控均使用阻塞式 `delay_ms`，主循环周期被动作时间绑架，按键响应最长延迟约 1.2 s。

详细分析与问题清单见 [`docs/第0版-代码结构分析.md`](docs/第0版-代码结构分析.md)。
