# ZYSTM32-A0 智能小车综合程序

湖南智宇电子 ZYSTM32-A0 智能机器人主板（STM32F103RCT6）综合程序：**黑线循迹 / 红外避障 / 红外遥控**，
板载 PC2 按键循环切换模式。

> 版本演进：`v1.0` 原厂 → `v2.0` 避障与非阻塞改造 → `v2.1/v2.2`（循迹未跑通）→ **`v3.0` 循迹跑通（融合"可循迹版本"）**

---

## v3.0 做了什么（重要）

把仓库里的 `可循迹版本/`（实车能稳定循迹的那份）和 v1.0 做了逐文件对比，结论很明确：

| 发现 | 说明 |
|---|---|
| **只有 `IRSEARCH.c/.h` 不同** | 可循迹版本没改电机、没改主循环，说明**原厂 `motor.c` 的通道映射是对的** |
| **v2.0 的电机"修复"是错的** | v2.0 把右轮挪到 CH4，导致 v2.x 车跑不直、循迹失败。v3 已改回：**左轮 CH4/PB9，右轮 CH3/PB8** |
| **v2.1 的 I2C 实现太简陋** | 缺总线恢复、PING 重试、通道使能(0xCE)、归一化(0xCF)，读出来是无效数据 |
| **可循迹版本读的是"归一化模拟量"** | 不是数字量；用 `黑权重 = 180 - 归一化值` 做加权重心，分辨率高得多 |

v3.0 = 可循迹版本的循迹算法 + v2.0 的非阻塞电机层 / 不停车避障 / 串口调试。

## 灰度传感器接线

**默认 I2C 方案**（`IRSEARCH.h` 里 `GRAY_IF_I2C = 1`）：

| 模块 | 接主板 | 说明 |
|---|---|---|
| VCC | 5V | |
| GND | GND | |
| SCL | **PB10**（IO16） | 5V 容忍脚 |
| SDA | **PB11**（IO15） | 5V 容忍脚 |
| PULL 跳线 | **必须短接** | 打开 5V 上拉，不短接通信必失败 |
| AD0 / AD1 | 不装 | 保持默认地址 `0x4C` |

**备选串行方案**（`GRAY_IF_I2C = 0`）：VCC→5V、GND→GND、**CLK→PB10**、**DAT→PB11**；
时序：CLK 拉低 → 2µs → 读 DAT → CLK 拉高 → 5µs，循环 8 次。

## 循迹参数（`SYSTEM/IRSEARCH/IRSEARCH.h`）

| 宏 | 默认 | 作用 |
|---|---|---|
| `GRAY_BASE_SPEED` | 40 | 直行速度 |
| `GRAY_STEER_GAIN` | 35 | **P**：满偏（±100）时的转向量 |
| `GRAY_KI` | 4 | **I**：积分系数，每累积 1000（误差·ms）贡献 4 的转向量；0 = 关闭 |
| `GRAY_KD` | 0 | **D**：微分系数；0 = 关闭（默认） |
| `GRAY_I_LIMIT` | 2500 | 积分累加上限（误差·ms），防积分饱和 |
| `GRAY_BLACK_CUTOFF` | 180 | 归一化值低于此算黑线（白≈255 黑≈0） |
| `GRAY_CENTER_DEADBAND` | 4 | 中线死区，防抖 |
| `GRAY_CHANNEL_MIRROR` | 0 | 车往反方向修正时改 1 |
| `GRAY_LOST_SPIN_SPEED` | 28 | 丢线原地找线速度 |
| `GRAY_LOST_STOP_MS` | 800 | 丢线多久后停车 |
| `GRAY_FRAME_MS` | 10 | 必须与 `main.c` 的 `TICK_MS` 一致 |

### PID 调参顺序（v3.1）

1. **先把 KI、KD 都设 0**，只调 P：`GRAY_STEER_GAIN` 从 35 开始，直线画龙就调小（25），压不住弯就调大（45）
2. **再加 I**：`GRAY_KI` 从 2 起步，观察"车是不是慢慢回到线中间"。加太多会看到车头先回中再甩出去（过冲），此时降回 2~4
3. **D 先别开**：误差已经过一阶低通，D 会把残留噪声放大；真要加，从 8~15 试，并做好再次降 KI 的准备
4. 串口看 `corr` 字段最直观：P 负责让它"随偏差变"，I 负责让它"最终能归零"


## 串口调试（115200，插 USB）

```
[BOOT] ZYSTM32-A0 v3.1  build ...
[BOOT] gray ready = 1 (ok)
mode=1 L=  40 R=  40 | err=   0 corr=   0 ready=1 avoid=1
```

- `ready=0` → 灰度模块没通：先查 **PULL 跳线**、SCL/SDA 是否接反、5V 供电
- `err`：0 居中、负数偏左、正数偏右、`999` 丢线
- 手拿车把某个探头压在黑线上，`err` 应有明显正负跳变 → 验证通道顺序
