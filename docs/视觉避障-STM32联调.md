# 视觉避障联调手册（STM32 ← K210）

> 分支：`feature/vision`　版本：v4.0　（主分支 v3.5 的超声波方案不动，互不影响）

---

## 0. 这条链路在干什么

```
K210：拍图 → 找障碍 → 算"偏左/居中/偏右" → 串口发 6 字节
                              ↓
STM32：USART2 中断收帧 → 校验 → 避障状态机 → 电机
```

两边各管一摊，谁挂了都不影响另一边：

| 模块 | 文件 | 职责 |
|---|---|---|
| K210 | `k210/vision_avoid.py` | 视觉识别 + 发帧 |
| STM32 | `SYSTEM/vision/vision.c/.h` | 收帧、校验、超时、避障控制 |
| STM32 | `USER/main.c` | 模式2 调 `Vision_AVoidRun()` |

---

## 1. 接线

| K210 | STM32 | 说明 |
|---|---|---|
| TX | **PA3**（丝印 IO0，USART2_RX） | 必接 |
| RX | PA2（丝印 IO1，USART2_TX） | 可不接（单向足够） |
| GND | GND | **必须共地** |
| 5V | 独立 5V | 别和电机共用，否则会重启 |

> PA2/PA3 在 F103 上不是 5V 容忍脚，但 K210 是 3.3V 电平，安全。
> 不要用 PA9/PA10（那是调试串口）、不要用 PB10/PB11（灰度 I2C）。

---

## 2. 协议

```
AA 55 | FLAGS | DIR | DIST | XOR
```

| 字段 | 取值 | 含义 |
|---|---|---|
| FLAGS | bit0=1 | 检测到障碍 |
| DIR | 0 | 障碍**偏左** → STM32 往**右**绕 |
| DIR | 1 | 障碍**居中** |
| DIR | 2 | 障碍**偏右** → STM32 往**左**绕 |
| DIST | 0~255 | 距离 cm，0=未知（视觉可填 0） |
| XOR | — | 前 5 字节异或 |

示例：障碍偏左 → `AA 55 01 00 00 AA`

> **STM32 端最多容忍 300ms 无帧**（`VISION_TIMEOUT_MS`），超时判"视觉失效"，
> 此时保持直行并打印 `vis=0`，不会乱转。

## 3. 分三步联调（不要一次全接上）

### 第 1 步：先让 STM32 能收到"假数据"

不接 K210，用 **USB-TTL 模块**接到 PA3，串口助手（115200）发十六进制：

```
AA 55 01 00 00 AA     → 障碍偏左（应往右绕）
AA 55 01 02 00 A8     → 障碍偏右（应往左绕）
AA 55 00 01 00 FF     → 无障碍（直行）
```

STM32 调试口（PA9/PA10，115200）应打印：

```
mode=2 L=  20 R=  90 | ... | vis=1 dir=0 dist=  0 st=1 n=37
```

- `n` 一直在涨 → 串口通了
- `vis=1` → 数据有效
- `st` 0=直行 1=绕行 2=回正
- 拔掉 USB-TTL，`vis` 应变成 0（300ms 后）

**这一步能过，说明 STM32 端完全 OK，后面只需要调 K210。**

### 第 2 步：K210 单独跑通

1. MaixPy IDE 打开 `k210/vision_avoid.py`
2. 把 `THRESHOLD_RED` 用"阈值编辑器"改成你障碍物的颜色
3. 运行，LCD 上应看到障碍物被绿框框住
4. 用 USB-TTL 接 K210 的 TX/GND，串口助手看是否收到 `AA 55 ...` 帧

### 第 3 步：接上联调

K210 的 TX → STM32 PA3，共地，上电。看调试口：

```
mode=2 ... | vis=1 dir=0 dist=0 st=1 n=120
```

把障碍物在镜头前左右移动，`dir` 应该在 0/1/2 之间跳，`st` 跟着变 1。

## 4. 参数（`SYSTEM/vision/vision.h`）

| 宏 | 默认 | 说明 |
|---|---:|---|
| `VISION_UART_BAUD` | 115200 | 与 K210 一致 |
| `VISION_TIMEOUT_MS` | 300 | 多久没帧算失效 |
| `VIS_BASE_SPEED` | 55 | 直行速度 |
| `VIS_OUTER_SPEED` | 90 | 绕行外侧轮 |
| `VIS_INNER_SOFT` | 20 | 普通绕行内侧轮 |
| `VIS_INNER_HARD` | -30 | 障碍居中且很近时，内侧轮倒转 |
| `VIS_NEAR_CM` | 30 | 小于它用 HARD 档（DIST=0 时不触发） |
| `VIS_HOLD_MS` | 450 | 一次绕行至少保持 |
| `VIS_RECOVER_MS` | 250 | 绕完反向回正 |

**调试顺序**：先调 `VIS_BASE_SPEED`（跑太快反应不过来就降到 40）→ 再调 `VIS_HOLD_MS`
（绕得不够就加到 600）→ 最后调 `VIS_INNER_HARD`（急转不够就 -30→-45）。

## 5. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `vis=0` 一直不变 | 串口没通 | 查 TX→PA3、共地、波特率 |
| `n` 不涨 | 帧格式不对 | 用串口助手核对字节顺序/校验 |
| 偶尔 `vis` 跳 0 | 帧率太低（<3fps） | 关 LCD、降分辨率到 QQVGA |
| 车乱转 | `dir` 抖动 | 给 K210 端加"连续 3 帧一致才发" |
| K210 反复重启 | 供电不足 | 独立 5V + 470µF 电容 |
| 白天好使晚上失灵 | 光照 | 加补光 LED，或改 YOLO（见 `docs/视觉避障-新手路线.md`） |

## 6. 和主分支的关系

- 主分支 `main` 的避障是 **超声波 v3.5**，本分支改成视觉，**没有改动主分支任何文件**
- `USER/main.c` 里 `#define AVOID_SRC_VISION 1`：改成 0 就回到原来的超声波/红外避障
- `SYSTEM/vision/` 是本分支新增目录，Keil 工程已加好（`VISION` 组 + include 路径）
- 合并时只需注意 `main.c` 的 include 与 `ModeTask` 两处
