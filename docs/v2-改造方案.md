## 1. 问题 1 根因：电机通道错位（先修这个）

### 1.1 现象
进入循迹模式后，只有左轮朝一个方向转，车不走直线、不循迹。

### 1.2 代码里的三处矛盾

`SYSTEM/motor/motor.h` 的引脚定义：

```c
#define LEFT_MOTOR_GO   GPIO_Pin_7   // PB7  左电机方向
#define LEFT_MOTOR_PWM  GPIO_Pin_8   // PB8  → TIM4_CH3
#define RIGHT_MOTOR_GO  GPIO_Pin_4   // PA4  右电机方向
#define RIGHT_MOTOR_PWM GPIO_Pin_9   // PB9  → TIM4_CH4
```

`SYSTEM/motor/motor.c` 的 `SetMotorSpeed()` 却写成：

```c
case 0:  //注释"右轮"
    TIM_SetCompare3(TIM4, sPWM);   // CH3 → PB8 ← 这是"左电机PWM"的脚！
    ... RIGHT_MOTOR_GO ...          // 方向写的是右轮 PA4
case 1:  //注释"左轮"
    TIM_SetCompare4(TIM4, sPWM);   // CH4 → PB9 ← 这是"右电机PWM"的脚！
    ... LEFT_MOTOR_GO ...           // 方向写的是左轮 PB7
```

即：**每一路指令 = 一个轮子的方向 + 另一个轮子的速度**。

### 1.3 为什么正好表现为"只有左轮单向转"

`ZYSTM32_Left()`（左转）的实现是：左轮置速度 0、右轮给 50。走一遍：

1. `SetMotorSpeed(1, 0)` → 左轮分支里 `cSpeed==0`，**方向脚一个都不写**；`CH4(PB9)` 占空比清零 → 右轮 PWM 通道被关掉。
2. `SetMotorSpeed(0, 50)` → `CH3(PB8)` 拿到 50% 占空比（而 PB8 按命名是**左电机**的 PWM），方向写的是**右电机**的 PA4。

结果：**左电机拿到 PWM（在转），右电机没有 PWM（不转），而左电机自己的方向脚 PB7 从头到尾没被更新过** → 只会朝上电时的那一个方向转。这与实测现象完全吻合。

> 顺带解释了"前进看起来还行"：`run()` 同时给 CH3、CH4 都写了占空比，两个方向脚也都写了，对称抵消后车能走直线，所以只从前进看不出问题。

### 1.4 修复方案（3 行代码 + 1 处加固）

```c
// motor.c
case 0:  // 右轮
    TIM_SetCompare4(TIM4, sPWM);        // CH4 → PB9（RIGHT_MOTOR_PWM）
case 1:  // 左轮
    TIM_SetCompare3(TIM4, sPWM);        // CH3 → PB8（LEFT_MOTOR_PWM）
```

另外把 `SetMotorSpeed()` 里"速度为 0 时不写方向脚"的写法改成**总是显式写方向**（0 也写），避免方向脚残留上一次状态。

### 1.5 修复后必须做一次"电机自检"（我会提供）
30 秒自检：左轮正转 1s → 停 → 左轮反转 1s → 停 → 右轮正转 1s → 停 → 右轮反转 1s → 停 → 双轮前进 1s。
- 若某轮反向 → 改 `MOTOR_DIR_INVERT_L / MOTOR_DIR_INVERT_R` 宏即可，不用改线。
- 若两轮"该转的不转" → 说明实际板子通道和原理图又不一样，我再按现象调。

## 3. 串口情况（回答"串口是不是空的"）

| 串口 | 引脚 | 状态 | 说明 |
|---|---|---|---|
| USART1 | PA9(TX) / PA10(RX) | **已用** | 板载 CH340G USB 转串口，插 USB 线即可在 PC 串口助手（**115200**）看到打印 |
| USART2 | PA2(TX) / PA3(RX) | **空闲** | 丝印 IO1 / IO0；本次不用 |
| USART3 | PB10(TX) / PB11(RX) | **空闲** | 丝印 IO16 / IO15；本次不用 |

**结论：串口不需要重新调整。**
原程序 `SYSTEM/usart/usart.c` 已经把 USART1 配好并重定向了 `printf`，只是 `main()` 里从来没调用 `uart_init()`。v2 只要在初始化里加一行 `uart_init(115200);`，再把调试宏打开，就能用 USB 线看到灰度值和电机状态。

> 需要你验证一下：烧好程序后插 USB，串口助手选 115200，应该能收到 `[BOOT] ZYSTM32-A0 v2`。如果收不到，说明 CH340 接的不是 PA9/PA10，我再调（这种情况才需要"重新调整串口"）。

## 4. 灰度传感器接线方案（感为 8 路，3 地址线 + 1 模拟输出）

### 4.1 感为模块的工作方式（来自你资料里的 `No_Mcu_Ganv_Grayscale_Sensor.c`）

- 模块内部是 8 路光电管 + 模拟开关；
- 用 **A0/A1/A2 三根地址线**选通道（0~7）；
- **AO** 输出当前通道的模拟电压，交给单片机 ADC 采样；
- 标准例程是"每路采 8 次取平均 + 白/黑两点校准 + 二值化"。

### 4.2 接线表（★ 就是你要的"什么接什么"）

| 感为模块引脚 | 接到主板 | MCU 引脚 | 方向 | 说明 |
|---|---|---|---|---|
| VCC | 3.3V 电源排针 | — | 电源 | **必须 3.3V，不要接 5V**（AO 最高会到 VCC，超过 3.3V 会打坏 ADC 口） |
| GND | GND 排针 | — | 电源 | |
| A0 | IO 排针 **0** | **PA3** | 输出 | 地址位 0 |
| A1 | IO 排针 **1** | **PA2** | 输出 | 地址位 1 |
| A2 | IO 排针 **2** | **PA0** | 输出 | 地址位 2 |
| AO | 模拟排针 **A0** | **PC0** | 模拟输入 | ADC1_IN10，12 位 |

> 为什么这么分配：地址线要的是普通输出脚，IO0/IO1/IO2 三根挨在一起最好插；AO 要 ADC，模拟排针 A0 就是为此设计的（PC0 = ADC1_IN10）。**四个脚全是空闲的，不动现有任何接线，也不占用 USART2/3。**

### 4.3 软件读数流程

```
for ch in 0..7:
    A2A1A0 = ch            // 3 根地址线
    delay_us(20)           // 等模拟开关稳定
    sum = 0
    for k in 0..7: sum += ADC1_IN10 采样
    value[ch] = sum / 8    // 0~4095
```

- 之后做一次**白/黑校准**：车放在白底上按一下键记录 `white[8]`，放黑线上再按一下记录 `black[8]`；
- 归一化：`norm[ch] = (value - black) * 1000 / (white - black)`，限幅 0~1000；
- 循迹用**归一化值**做加权，二值化只用于"是否丢线"判断。

### 4.4 落地时的代码注释

我会在 `SYSTEM/gray/gray.h` 顶部用注释把上面这张接线表原样写进去，并在每个宏旁边标明"丝印 IO0 / PA3"这种双标识，避免以后接线对不上。

## 5. 循迹算法（v2 用灰度替掉原来的 2 路开关量）

原方案是"双探头 + 开关量 + 固定 50 速度"，本质是 Bang-Bang，弯道必冲出去。v2 改成 PD：

```
误差 e = Σ(权重i × 归一化值i) / Σ(归一化值i)     // 权重 -3.5 ~ +3.5
转向 steer = Kp·e + Kd·(e - e_prev)
左轮 = 基础速度 + steer
右轮 = 基础速度 - steer
```

- 基础速度、Kp、Kd 都用宏放在文件头，方便你现场调；
- **丢线处理**：8 路全白（跑出赛道）→ 按上一次误差的方向原地/差速找线，最多找 800ms，找不到就停车；
- **十字/全黑**：8 路全黑 → 短暂直行冲过去（可配置"遇到全黑直行 N ms"）；
- 原来的 `IRSEARCH` 两路探头**保留不删**，作为兜底/对照（宏切换）。

## 6. 避障新方案（不停车、不后退）

### 6.1 现状 vs 目标

| | 现状（v1） | 目标（v2） |
|---|---|---|
| 检测到障碍 | 停车 300ms → 后退 400ms → 左转 500ms | **不停车、不后退**，直接差速弧线绕开 |
| 期间能否重新检测 | 不能（阻塞 1.2s） | 能（每 10ms 采样一次） |
| 方向 | 写死左 | 宏 `AVOID_TURN_DIR`，默认左 |

### 6.2 实现（非阻塞差速）

```
直行：     左 = 60，右 = 60
检测到障碍：内侧轮降到 10~20，外侧轮提到 85~95   → 车沿弧线直接绕过去
           同时锁定"避让保持时间" 400ms（防止刚转一点又检测到而抖动）
保持时间到：恢复直行，若又检测到 → 继续加深转弯
```

关键在于**把电机层改成非阻塞**：`Motor_SetSpeed(左, 右)` 立刻返回，不再 `delay_ms`。主循环 10ms 一拍，读传感器 → 算 PWM → 写寄存器，全程不阻塞，所以"边转边看"成为可能。

### 6.3 可选增强（需要你多接一根线）
再加一个右侧避障探头（比如挂到空闲的 **IO6 / PA8**），就能"左有障碍往右绕、右有障碍往左绕"，而不是固定方向。**默认不改，先按单探头跑通。**
