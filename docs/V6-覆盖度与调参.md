## 1. 为什么加"覆盖度"

原来的误差是加权重心：

```
权重 = 180 − 归一化值        （越黑权重越大）
位置 = ±7 ±5 ±3 ±1
error = Σ(w·pos) / (Σw·7) × 100        → −100 ~ +100
```

这组权重是**对称**的，所以：

| 场景 | 8 路读数 | error |
|---|---|---|
| 正常压在 2cm 黑线上（占 3~4 路） | 部分黑 | 随位置变化 |
| 压在十字 / 5cm 宽黑带 / 停车线上 | 8 路全黑 | **恰好 0** |

也就是说，**"线很正"和"地上一大片黑"给出的是同一个数**。原来车过十字能直着走，
不是因为识别到了十字，而是因为"恰好对称"——地上稍微有点坡、两轮稍微不一致，
出十字时车身就歪了，而且代码完全看不出来。

V6 增加一个独立量 **active（几路压线）**，把它和位置误差分开：

```
active >= WIDE_MIN(默认 7)  → EV_WIDE
active == 0 且 Σw < 100     → EV_LOST
其余                        → EV_LINE
```

## 2. 事件分层：采样 → 事件 → 决策 → 控制

```
┌──────────────┐   ┌──────────────────┐   ┌───────────────┐   ┌──────────────────┐
│ ① gray_read_ │   │ ② gray_update_   │   │ ③ switch(ev)  │   │ ④ PID + 斜坡 +   │
│    frame()   │──▶│    event()       │──▶│   决策        │──▶│   限幅 → 电机     │
│ error+active │   │ LINE/WIDE/LOST   │   │ 走不走 PID？  │   │                  │
└──────────────┘   └──────────────────┘   └───────────────┘   └──────────────────┘
```

| 事件 | 判据 | 决策 |
|---|---|---|
| `EV_LINE` | 1~6 路压线 | 正常 PID（滤波/死区/增益调度/速度调度） |
| `EV_WIDE` | >= `WIDE` 路压线，连续 3 帧 | **不走 PID**，误差锁 0，按 base 直行；计一次"十字" |
| `EV_LOST` | 一路都没压实，连续 3 帧 | 朝最后方向原地找（沿用原逻辑），超 3s 停车 |

要点：

- **进事件要连续 N 帧确认**（去抖），**退事件立刻生效**（避免卡在 `EV_WIDE`）。
- 过宽黑时清零积分、清滤波状态，出宽黑后重新起滤，防止把 0 当历史值拖出抖动。
- `Gray_GetCrossCount()` 记录"过了几个十字/横线"，可以拿来做计圈或停车判断。
- 需要"宽黑持续太久就停车"（终点黑区）时，把 `GRAY_WIDE_STOP_MS` 设成非 0，
  例如 `800` 表示宽黑持续 800ms 就停。

串口调试行新增两个字段：

```
mode=3 ... ev=WIDE act=8  cc=2 | ready=1 ...
          ↑事件   ↑几路  ↑第几个十字
```

## 3. 加速斜坡

原来 `Motor_SetSpeed(base+corr, base−corr)` 是阶跃：切模式、找回线、避障绕完，
base 从 0 直接跳到 60，轮胎打滑、车尾一甩。

V6 只对**基础速度**做斜坡，差速修正量**不经过**斜坡：

```
base_ramp += (base_target − base_ramp) × RAMP / 1000     每 10ms 一次
左 = base_ramp + correction
右 = base_ramp − correction
```

这样：

- 起步/找回线是缓加速（`RAMP=120` ≈ 80ms 时间常数，0→60 约 250ms）；
- 急弯里内轮该反转还是**立刻**反转，不会因为斜坡转不动。

`RAMP = 1000` 等于关闭斜坡，一键退回 V5 行为。

## 4. 串口调参 + Flash 存参

16 个最常动的参数从 `#define` 搬到了 RAM（`SYSTEM/cfg/`），串口直接改：

| 命令 | 作用 |
|---|---|
| `?` | 打印全部参数 |
| `BASE 55` 或 `SET BASE 55` | 改一个参数（立即生效，未存盘） |
| `SAVE` | 写入内部 Flash（回读校验，返回 OK/FAIL） |
| `LOAD` | 从 Flash 重读 |
| `DEF` | 恢复默认（只改 RAM，要存再 `SAVE`） |
| `HELP` | 命令帮助 |
| `1` / `2` / `3` / `4` | 切模式（整行只能是这**一个**字符） |

参数名：`BASE GAIN FAR THD KD KI SLOW SLOWD MIN REV CUT FULL REF RAMP WIDE DEAD`

```text
> ?
[cfg] BASE=60 GAIN=40 FAR=60 THD=30 KD=12 KI=0
[cfg] SLOW=20 SLOWD=40 MIN=25 REV=45 CUT=180 FULL=55 REF=60
[cfg] RAMP=120 WIDE=7 DEAD=2  src=FLASH
> BASE 55
[cfg] BASE = 55  (未存盘)
> SAVE
[cfg] save ... OK
```

**存储位置**：`0x0803F800`，256KB 版 F103RC 的最后一页（2KB）。
工程里 IROM 已经缩到 `0x3F800`（254KB），链接器不会把代码放到那一页上；
如果换成 128KB 的芯片（RBT6/C8T6），把 `cfg.c` 里的 `CFG_FLASH_ADDR` 改成
`0x0801F800`。

**格式**：`magic(0x5A5A) | ver | count | 16×int16 | crc16(CCITT)`。
任一字段不对就用默认值——不会把写坏的数据当参数跑。

> ⚠️ `SAVE` 会擦一页 Flash，期间关中断 20~40ms。**建议停车后再存**，
> 跑动中存会丢几个 5ms 节拍（不会炸，但没必要）。

## 5. 自检模式（模式 4）

上车前按到模式 4，串口会依次点名：

| 步骤 | 内容 | 判据 |
|---|---|---|
| 1 | 灰度连读 5 帧，打印 8 路裸值 + `act` | `ready` 且至少读到一帧 |
| 2 | 左轮 +50 / 右轮 +50 / 双轮 +40，各 600ms | 靠人看轮子（必然 PASS，但能看出停转/反向） |
| 3 | 舵机 170° → 10° → 90° | 靠人看 |
| 4 | 超声波连测 3 次取中位数 | 中位数 > 0 |
| 5 | 4 秒内按一下 PC2 | 电平发生变化 |
| 6 | 4 秒内按遥控器任意键 | 收到有效键值 |
| 7 | 打印参数 + Flash 状态 | 上电参数来自 Flash |

全部通过时 **D3 常亮**，有失败则 **D3 灭**——不接串口也能一眼看出结论。

按 PC2（或串口发 `1`/`2`/`3`）随时退出。

## 6. 改完之后怎么验（建议顺序）

1. **编译**：Keil 打开 `USER/Template.uvprojx`，新增了 `cfg.c` / `selftest.c`
   两个文件，已经写进工程和头文件路径，直接 Build 即可。
2. **上电看 banner**：应多一行 `[cfg] ...`（从 Flash 读取 / 用默认值）。
3. **模式 4 自检**：先把 7 项过一遍，确认硬件没坏。
4. **模式 3 单跑循迹**，串口盯 `ev/act/corr/spd`：
   - 直道上 `act` 应该 2~4；
   - 手动把车压到一条宽黑带上，`act` 应跳到 7~8 且 `ev=WIDE`；
   - 拿起车（丢线）3 帧后应变成 `ev=LOST`。
5. **过十字**：`cc` 每过一个 +1；如果 `cc` 在直线上乱加，说明 `WIDE` 太小
   （线比预想的宽），调到 8 或关闭（设 9）。
6. **调参**：`BASE`/`GAIN` 现场改，满意了 `SAVE`；下次上电看 `src=FLASH`。

## 7. 已知边界

- **停车线 vs 十字**：8 路传感器只看"宽度"，分不出"横向细线（停车线）"和
  "大片黑（十字）"。要区分得靠**持续时间**（`GRAY_WIDE_STOP_MS`）或
  加第二排探头。当前默认只计数、不停车。
- **`ev=WIDE` 期间不纠偏**：靠 base 直行，如果地面明显倾斜，几十毫秒内会偏
  一点——这比"在十字里被误差拉走"好，但不如"加陀螺锁航向"（V7 再做）。
- **丢线找回仍是定时**：`GRAY_LOST_STOP_MS` 是时间判据，电池电压变化会影响
  实际转过的角度；加 MPU6050 后可改成定角（V7）。
