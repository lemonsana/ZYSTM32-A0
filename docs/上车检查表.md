# 上车检查表

> 每次上场前 2 分钟过一遍。形式抄自 TC387 智能车工程里那份"技术手册"——
> 那份文档本质就是一张检查清单，只是写得比较散。这里按**上电 → 自检 → 低速 → 高速**
> 四段整理，对应本工程的模式和串口字段。

---

## ① 上电前（不插电池）

| 检查项 | 怎么看 | 不对怎么办 |
|---|---|---|
| 灰度模块 **PULL 跳线**是否短接 | 模块背面跳线帽 | 不短接通信必失败，`ready=0` |
| 灰度 SCL/SDA 是否接反 | PB10=SCL、PB11=SDA | 接反了 `ready=0` |
| 灰度 5V / GND | 万用表量模块 VCC | 电压低于 4.6V 会导致读数漂 |
| 电机线、轮子 | 手拨两轮是否同阻力、有无异物缠绕 | 清异物；卡滞会跑偏 |
| 轮子是否沾灰/磨平 | 目视 | 擦干净；磨平换轮 |
| 电池电压 | 万用表 ≥ 7.4V（2S） | 低于 7.0V 不要上高速，掉压会改转向手感 |
| 超声波探头方向 | 正前方、无遮挡 | 歪了避障会误判 |
| 舵机中位 | 上电后应在 90° | 不在中位说明舵机被卡或供电不足 |

## ② 上电后（车架空，轮子不着地）

串口 115200，看启动行：

```
[BOOT] ZYSTM32-A0 V6  build ...
[BOOT] gray ready = 1 (ok)
[cfg] 从 Flash 读取, 16 项
```

| 检查项 | 期望 | 不对怎么办 |
|---|---|---|
| `gray ready = 1` | 1 | 0 → 查 PULL 跳线 / 接线 / 5V |
| `[cfg]` 来自 Flash | 调过参的车应显示"从 Flash 读取" | 显示"用默认值"→ 之前没 `SAVE`，或 CRC 坏了 |
| 按 PC2 能切模式 | 串口回 `T2`/`T3`/`T4` | 检查 STARTUP_MS 屏蔽期（上电 500ms 内按键无效） |

## ③ 自检（模式 4）

按 PC2 切到模式 4，**车架起来**，跟着串口走完 7 步：

- [ ] 灰度 5 帧都有数，`act` 在 2~4（压在线上时）
- [ ] 左轮转、右轮转、双轮转，方向都往前
- [ ] 舵机 170 → 10 → 90，扫到位、不抖
- [ ] 超声波 3 次数值接近，手挡在前面能掉到 30cm 以内
- [ ] 按键有反应
- [ ] 遥控有反应
- [ ] 最后 `===== 结果 =====` 全 PASS，**D3 常亮**

有 FAIL 就别上路，先修那一项。

## ④ 低速验证（模式 3，纯循迹）

| 检查项 | 期望 | 对应串口字段 |
|---|---|---|
| 直道不画龙 | 车头小幅修正 | `corr` 在 ±10 内摆动 |
| 手推车压到宽黑带 | `ev=WIDE`、`act>=7` | 用来验证十字判据 |
| 拿起车（丢线） | 约 3 帧后 `ev=LOST`，原地找线 | `err=999` |
| 过十字 | `cc` +1，车直着过去 | `cc` |
| 出弯不冲出去 | `spd` 在弯里下降 | `spd` 掉到 MIN 附近属正常 |
| 车轮不打滑 | 起步是"推"出去不是"弹"出去 | 斜坡 `RAMP` 生效 |

低速跑顺了再进模式 1（循迹+避障），最后才提 `BASE`。

## ⑤ 高速前（每次改完参数）

- [ ] 改过 `BASE`/`GAIN` 后，**先用低速验证一圈**
- [ ] `SAVE` 之后断电重启，确认 `src=FLASH` 且参数没回退
- [ ] 高速跑之前清一次 `cc`（重新上电即可），方便数十字

## 常见现象 → 先查什么

| 现象 | 先查 |
|---|---|
| 车不动、`ready=0` | PULL 跳线、SCL/SDA 接反、5V |
| 车往白底跑（把白当黑） | `GRAY_ANALOG_INVERT`（本车实测为 1） |
| 直道画龙 | `GAIN` 调小；`DEAD` 适当加大 |
| 弯道切不进去 | `GAIN`/`FAR` 调大；`FULL` 调小（更早满舵） |
| 十字里被拉偏 | 看 `ev` 是不是 WIDE；不是就把 `WIDE` 调小（7→6） |
| `cc` 在直线上乱加 | 线比预想宽，`WIDE` 调大（7→8）或设 9 关闭 |
| 起步弹射/打滑 | `RAMP` 调小（120→80） |
| 冲过障碍才停 | `FUS_TRIGGER_CM` 调大 |
