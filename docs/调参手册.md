# ZYSTM32-A0 调参手册（v3.4）

> 所有参数都在头文件的宏里，改完**重新编译烧录**即可，不用改逻辑代码。
> 每个参数名下面都写了"现象 → 怎么改"，直接对号入座。

## 0. 快速定位

| 想调什么 | 去哪个文件 | 宏 |
|---|---|---|
| 循迹 PID、速度、丢线 | `SYSTEM/IRSEARCH/IRSEARCH.h` | `GRAY_*` |
| 避障绕行 | `SYSTEM/IRAvoid/IRAvoid.c` 顶部 | `AVOID_*` |
| 电机方向/通道反了 | `SYSTEM/motor/motor.h` | `MOTOR_DIR_INVERT_L/R`、`MOTOR_PWM_CH_SWAP` |
| 主循环节拍、串口开关 | `USER/main.c` | `TICK_MS`、`DEBUG_UART` |

> `TICK_MS` 和 `GRAY_FRAME_MS`、`AVOID_TICK_MS` **必须相等**（现在都是 10ms），否则积分/计时全错。

## 1. 循迹（`IRSEARCH.h`）

### 1.1 当前默认值速查

| 宏 | 值 | 单位/范围 | 一句话 |
|---|---:|---|---|
| `GRAY_LOOKAHEAD_CM` | 12 | cm | 只是记录，不参与计算 |
| `GRAY_BASE_SPEED` | 32 | 0~100 | 直行速度 |
| `GRAY_STEER_GAIN` | 32 | 0~60 | P：小误差增益 |
| `GRAY_STEER_GAIN_FAR` | 50 | 0~80 | P：大误差增益 |
| `GRAY_FAR_THRESHOLD` | 40 | 0~100 | 切换增益的阈值 |
| `GRAY_KI` | 0 | 0~10 | I：积分 |
| `GRAY_KD` | 12 | 0~40 | D：微分 |
| `GRAY_I_LIMIT` | 2500 | 500~5000 | 积分上限（误差·ms） |
| `GRAY_BLACK_CUTOFF` | 180 | 100~220 | 黑白判定阈值 |
| `GRAY_CENTER_DEADBAND` | 4 | 0~10 | 中线死区 |
| `GRAY_CHANNEL_MIRROR` | 0 | 0/1 | 探头顺序镜像 |
| `GRAY_SLOW_GAIN` | 20 | 0~40 | 按误差降速 |
| `GRAY_SLOW_D_GAIN` | 40 | 0~80 | 按误差变化降速 |
| `GRAY_MIN_SPEED` | 18 | 0~40 | 最低速度 |
| `GRAY_INNER_REVERSE` | 45 | 0~70 | 内轮反转上限 |
| `GRAY_LOST_SPIN_SPEED` | 50 | 0~70 | 丢线找线速度 |
| `GRAY_LOST_STOP_MS` | 3000 | ms | 丢线多久停车 |

### 1.2 控制链路（先理解再调）

```
8路模拟量 → 加权重心(error ±100) → 一阶低通 → 死区 → PID → 差速输出
                                        ↓
                              base 随 |error|、|Δerror| 降速
```

- `error > 0`：线在**右边**；`error < 0`：线在**左边**
- `corr = P + I + D`，左轮 = `base + corr`，右轮 = `base − corr`

### 1.3 逐项调参表

| 现象 | 改哪个 | 怎么改 | 原因 |
|---|---|---|---|
| 直线上左右**画龙** | `GRAY_STEER_GAIN` | 32 → 25 → 20 | P 太大会过冲 |
| 弯道**切不进去**、转向不足 | `GRAY_STEER_GAIN` / `GRAY_STEER_GAIN_FAR` | 32→38，50→60 | P 不够 |
| 只有**急弯**转向不足 | `GRAY_FAR_THRESHOLD` | 40 → 30（更早切大增益） | 大增益介入太晚 |
| **出弯甩尾**、进弯冲过头 | `GRAY_KD` | 12 → 18 → 24 | 阻尼不足 |
| 车**发抖**、电机嗡嗡响 | `GRAY_KD` | 12 → 6 → 0 | D 放大了噪声 |
| 车总贴**同一侧**跑、回不到正中 | `GRAY_KI` | 0 → 2 → 4 | 有静差 |
| 加了 I 之后**过冲更严重** | `GRAY_KI` | 回到 0 或 1 | 前视 12cm 时积分易积累 |
| **过弯前不减速**、冲出去 | `GRAY_SLOW_GAIN` / `GRAY_SLOW_D_GAIN` | 20→30，40→60 | 减速不够 |
| 整体太慢、过弯磨叽 | `GRAY_MIN_SPEED` / `GRAY_SLOW_GAIN` | 18→25，20→12 | 减速过头 |
| **急弯拐不过来** | `GRAY_INNER_REVERSE` | 45 → 60 | 转弯半径不够小 |
| 弯里**车尾扫**、轮胎打滑 | `GRAY_INNER_REVERSE` | 45 → 30 | 内轮倒转太多 |
| 掉线后**找不回来** | `GRAY_LOST_SPIN_SPEED` / `GRAY_LOST_STOP_MS` | 50→60，3000→5000 | 找线太慢/太短 |
| 掉线后**乱转圈** | `GRAY_LOST_SPIN_SPEED` | 50 → 35 | 找线太快 |
| 车**往反方向**修正 | `GRAY_CHANNEL_MIRROR` | 0 ↔ 1 | 探头顺序反了 |

### 1.4 建议的调参顺序

1. **清场**：`KI=0`、`KD=0`，只留 P
2. **调 P**：直线上从 32 开始，画龙就降、拐不动就升，找到"刚好不摆"的值
3. **加 D**：12 起步，出弯甩尾就加，发抖就减
4. **调速度调度**：最后再动 `SLOW_*` 和 `MIN_SPEED`
5. **I 最后考虑**：只有"总是偏一侧"才加，且从 2 开始

## 2. 融合模式（v3.6，模式 1：循迹 + 避障）

```
循迹直行 ──前方<35cm──→ 停车 → 舵机扫 中/左/右 → 选远侧
    → 转向绕行 600ms → 原地反向慢转找灰度线 → 找到 → 冷静 400ms → 回到循迹
```

| 宏（`USER/main.c` 顶部） | 默认 | 现象 → 改法 |
|---|---:|---|
| `FUS_TRIGGER_CM` | 35 | 撞上才躲 → 调大（50）；太早躲 → 调小（25） |
| `FUS_TURN_MS` | 600 | 绕完回不到线 → 调大（800）；转过头 → 调小（450） |
| `FUS_SEEK_SPEED` | 40 | 找不到线 → 调大（55）；找线冲过头 → 调小（30） |
| `FUS_SEEK_TIMEOUT_MS` | 2500 | 找线超时后先回循迹 |
| `FUS_COOLDOWN_MS` | 400 | 刚上线又被触发 → 调大（700） |
| `FUS_MIN_GAP_CM` | 20 | 两侧都窄于它 → 原地掉头 |

### 调参顺序

1. 先让模式 2（纯避障）跑通：扫描/转向正常
2. 再用模式 1（综合）：只看"遇到障碍能不能停下并扫描"
3. 调 `FUS_TURN_MS`：绕过去后车头要能转回到线附近
4. 调 `FUS_SEEK_SPEED`：找线要能"扫到线就停"
5. 最后调 `FUS_COOLDOWN_MS` 防抖

### 调试字段 `fus`

| 值 | 状态 |
|---|---|
| 0 | 循迹中 |
| 1 | 停车扫描 |
| 2 | 转向绕行 |
| 3 | 原地找线 |
| 4 | 冷静期 |

## 3. 纯避障（`IRAvoid.h` 顶部，v3.5 超声波 + 舵机，模式 2）

### 3.1 两版切换

改 `AVOID_SCAN_WHILE_DRIVING` 一个宏，重新编译即可：

| 值 | 版本 | 行为 | 何时用 |
|---|---|---|---|
| **0（默认）** | 停车扫描版 | 前方<40cm → **停车** → 舵机扫 中/左/右 → 选远侧 → 转向 → 回正 | 场地小、障碍多、要最稳 |
| 1 | 边走边扫版 | 不停车，舵机 90°±40° 来回扫，前方±20°<40cm 就朝最空侧弧线绕 | 场地大、要流畅 |

```
停车扫描版：
  IDLE 直行 ──前方<40cm──→ 停车 → SCAN(中90°→左170°→右10°，每步停 250ms 测距)
                → 选远侧（两侧都<25cm → 原地掉头）→ TURN 700ms → RECOVER 300ms → IDLE

边走边扫版：
  IDLE 直行 + 舵机扫(90±40°，步进 20°) ──前方±20°内<40cm──→ TURN 朝"最空侧"弧线绕过
                → RECOVER 回正+回中 → IDLE
```

### 2.2 参数表

| 宏 | 默认 | 现象 → 改法 |
|---|---:|---|
| `AV_TRIGGER_CM` | 40 | **撞上了才停** → 调大（60）；**太早停** → 调小（30） |
| `AV_CLEAR_CM` | 55 | 判断"能走"的门槛，一般 = 触发值 + 15 |
| `AV_MIN_GAP_CM` | 25 | 两侧都窄于它 → 原地掉头 |
| `AV_SERVO_LEFT/RIGHT` | 170/10 | 扫描极限角；舵机机械卡住就收到 160/20 |
| `AV_SWEEP_HALF` | 40 | 边走边扫版扫描半角；扫太宽车会晃 → 30 |
| `AV_BASE_SPEED` | 55 | 直行速度（避障模式专用） |
| `AV_TURN_OUTER/INNER` | 85/0 | 转向差速；转不过来 → 内轮给 -20 |
| `AV_TURN_MS` | 700 | 一次转向时长；转不够 → 900 |
| `AV_SETTLE_MS` | 250 | 舵机到位等待；测距跳变 → 300 |
| `AV_MEAS_PERIOD_MS` | 100 | 直行测距周期 |

> ⚠️ 超声波测距**依赖反射面**：斜面、软质（布/海绵）、细杆会测不到或测偏。
> 探不到时 `dist=0`，程序按"没有障碍"处理。

## 3. 电机层（`motor.h`）

| 宏/接口 | 说明 |
|---|---|
| `MOTOR_DIR_INVERT_L/R` | 改 1 = 该轮正反转对调（不用改接线） |
| `MOTOR_PWM_CH_SWAP` | 改 1 = 左右 PWM 通道整体对调（板子批次不同时用） |
| `Motor_SetSpeed(左,右)` | 正数=前进，范围 −100~+100，**非阻塞** |
| `SetMotorSpeed(ch,spd)` | 原厂接口：`ch=0` 右轮、`ch=1` 左轮（左轮**负数才是前进**，历史约定） |

> 实测通道：**左轮 = PB7 方向 + PB9(CH4) PWM；右轮 = PA4 方向 + PB8(CH3) PWM**。
> `motor.h` 里 `LEFT_MOTOR_PWM` / `RIGHT_MOTOR_PWM` 两个宏名与实测相反，是历史遗留，已注释说明。

## 4. 串口字段

```
mode=2 L=   0 R=   0 | err= 999 corr=   0 spd=  0 ready=1 st=1 dist= 28 ang=170
```

| 字段 | 含义 | 正常范围 |
|---|---|---|
| `mode` | 1 循迹 / 2 避障 / 3 遥控 | 1~3 |
| `L`/`R` | 左右轮当前速度 | −45~95 |
| `err` | 线位置误差 | −100~100；**999=丢线** |
| `corr` | PID 输出 | ±50 左右，满舵说明在急弯 |
| `spd` | 调度后的基础速度 | 18~32 |
| `ready` | 灰度模块就绪 | **1**；0 说明 I2C 没通 |
| `st` | 避障状态 | 0 直行 / 1 扫描 / 2 转向 / 3 回正 |
| `dist` | 超声波距离 | 0=无回波；正常 2~200cm |
| `ang` | 舵机角度 | 90=正前，170=最左，10=最右 |

## 5. 常见故障 → 改哪里

| 故障 | 首要排查 | 次要调整 |
|---|---|---|
| `ready=0` | PULL 跳线、SCL/SDA 接线、5V 供电 | 换模块 |
| 车不走 / 只有一个轮转 | `MOTOR_PWM_CH_SWAP`、`MOTOR_DIR_INVERT_*` | 检查电机线 |
| 循迹方向反了 | `GRAY_CHANNEL_MIRROR` | — |
| 循迹能跑但很慢 | `GRAY_BASE_SPEED`、`GRAY_MIN_SPEED` | — |
| 发夹弯必掉线 | 正常（几何限制 R<20.6cm） | 改硬件缩短前视距离 |
| 避障撞上去 | `AV_TRIGGER_CM` 调大、`AV_TURN_MS` 调大 | 检查 TRIG/ECHO 接线 |
| `dist` 一直为 0 | TRIG=PC0 / ECHO=PC1 是否接对；模块 5V 供电 | 换模块 |
| 舵机不转/抖动 | PB0 是否接对；舵机是否独立 5V 供电 | 改 `AV_SERVO_LEFT/RIGHT` 极限角 |
